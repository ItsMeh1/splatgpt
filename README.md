# 🫟 SplatGPT
A static, data-driven assistant for the Splatoon series.

## ？How it works
In the [data folder](./data), lots of data is held for Splatoon 1, 2, and 3. The "bot" then searches through that data based on the users request. It also gets data from various other sources, being:
- Local datasets contributed to by the community
- Mined game data from various different sources all over the internet
- Live rotation data, previous season's X Battle rankings, etc from [Splatoon3.ink](https://splatoon3.ink)
- If you enter your own API key, you can get more competitive Splatoon data from [Sendou](https://sendou.ink)
