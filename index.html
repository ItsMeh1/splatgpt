About

Terms of use, data sources, and credits.

Local data

What is this?

SplatGPT is a fan-made, static reference-based assistant for Splatoon 1, 2, and 3. It searches community created datasets, shows live rotations, archived X rankings, and links to competitive build resources. There is no account system and no server: the site is static files, and your chats, settings, and what it learns about you stay in this browser and are private.

Terms of use

This is an unofficial fan project. Not affiliated with, endorsed, or sponsored by Nintendo. Splatoon and all related game content are trademarks of Nintendo. Data is provided as-is for reference; rotations, rankings, and builds can change at any time. Do not enter Nintendo, sendou.ink, or other account passwords here — the only token this app accepts is a sendou.ink read token, stored locally and sent only to sendou.ink.

Data sources & credits

  • Local datasets (community-contributed data on weapons, maps, modes, story mode, etc)
  • Mined game parameters and text (weapon stats, kits, gear, abilities, Salmonids): splat3-data, imported via scripts/import_gamedata.py
  • Live rotations, salmon run shifts, icons, and X Battle data from splatoon3.ink
  • Ranking snapshots: SplatNet 3 via splatnet3-scraper
  • Community build kits: scraped ahead of time from sendou.ink/builds by scripts/fetch_builds.py and served from data/builds.json (sendou.ink is AGPL-3.0; its data is credited here and linked from every build card). sendou.ink sets no CORS headers, so builds are snapshotted at build time rather than fetched live. Refreshed daily by the update-builds GitHub Action.
  • Gear and ability reference cross-checked against stat.ink's public API; gear and ability images via the sendou.ink public asset CDN
  • Your chats, notes and learned preferences never leave this browser
  • Some icons from Font Awesome.
